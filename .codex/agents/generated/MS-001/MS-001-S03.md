## Work and observable result

1. Inspect the restored S02 producer, Dockerfiles and schema/policy. Use upstream
   prebuilt PyArrow and other ordinary packages. Prefer a compatible binary version
   update over maintaining a custom build; verify the relevant existing imports,
   Parquet/IPC/artifact behavior when the dependency version actually changes.
2. Make the smallest explicit `internal-development` profile extension to the
   existing bundle path. It must allow genuinely unsigned/report-only internal
   output without fake signatures or gate passes, while preserving strict existing
   release inputs. Unsupported reader/profile combinations must fail clearly.
3. Produce the complete local bundle first. Bind source commit/locks, API/Web and
   PostgreSQL roles, ARM64/AMD64 image identities, Compose/resource file hashes and
   migration identity. Use one actual build per required platform; reuse an existing
   build only if its exact inputs/identity are established. No mandatory double
   rebuild, compiler dependency graphs, v2 source sets or companion downloader.
4. Retain upstream LICENSE/NOTICE files and available package/SBOM/license/scanner
   reports. Findings, missing metadata and unavailable optional scanner tools are
   reported; they do not automatically block this internal development bundle.
   Do not install new scanners or start license-by-license research just to make
   S03 green. Actual required payload/runtime failures still block. Before any
   external redistribution, meet applicable third-party conditions; owner-local
   development is the fallback, not a fabricated legal exception.
5. Save a unique protected local copy in the plan's existing owner directory.
   Include exact acquisition/verification/import commands and note whether images
   are retrieved from existing digests, retained local archives or the local engine.
   No implicit push to a public registry. Hosted signing is not an entry or
   completion requirement for this internal output. Record real size/timing once;
   image size targets are advisory. Let S04 prove clean consumer/runtime behavior.
