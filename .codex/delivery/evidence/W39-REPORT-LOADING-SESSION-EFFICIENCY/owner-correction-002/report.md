## Implementation

The existing header becomes a direct workspace child spanning both columns.
Report navigation and right inspector start beneath it. The toggle has accurate
expanded state, control target and Open/Close accessible name. Grid animation
and reduced-motion handling remain. Narrow right docks use the content row,
leaving header/tabs accessible; hidden report content is inert.

The shared navigation CSS gives the rail, optional left dock and workspace their
own columns. Panel height follows content with a viewport maximum and internal
scrolling; menu-group switching reuses its position. Below 641 px the dock uses a
row above the workspace, capped at 45dvh. Source modal backdrop/trap behavior is
adapted through runtime seams; native Tab order can leave the dock, Escape
restores the rail opener, and sibling workspace clicks do not close it. The
source HTML remains generated byte-for-byte from the preserved pilot.

The former 40 px navigation-row height was insufficient after its responsive
layout stacked tabs and context controls. Independent Browser QA found a 6.1 px
title/tab overlap at 400 px. Auto row height fixes the actual containment defect;
targeted tests assert tabs lie below header/title and inside chrome in all four
dock states, for both report generations.

Add finds an empty personal set with its unmodified bilingual automatic name,
reselects it and opens Set configuration. A renamed or populated set permits a
new one. Synchronous draft-reference updates make repeated/rapid events consult
the latest worksets. New names and copy names avoid existing bilingual labels.
Copies still allocate independent instance IDs and preserve metric references.
Existing names, IDs, cards, ordering and data are not rewritten. The 20-set limit
still applies to creation while resuming an existing unfinished set is allowed.
