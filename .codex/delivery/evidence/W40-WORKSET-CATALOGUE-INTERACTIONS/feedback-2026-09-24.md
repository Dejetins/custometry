# Owner browser feedback correction, 2026-09-24

This bounded correction follows [W40](../../tickets/W40-WORKSET-CATALOGUE-INTERACTIONS.md) and supersedes the original save-as-new interaction described in [initial evidence](report.md).

## Outcome

- Focus outlines now coincide with control edges. Card keyboard focus uses an inset ring on the card itself, not an offset pseudo-element outline.
- Day-grain tables omit the duplicate exact-date column. Other grains retain useful range boundaries; single-day ranges contain one date.
- Cancel has a separate right-aligned footer below the rename/delete actions.
- Save report persists the whole report definition and applied results. Create set copy only adds an explicitly named copy to the draft; it never calls the save endpoint. The second report-save control is removed.
- Apply/error/conflict status and retry controls reside in the inspector. Status appearance no longer changes the workset/card vertical position.
- Period differences toggles dashed connectors with horizontal percentage badges between temporal comparison series. Percentages are server-provided; no analytical calculation is introduced. Null comparisons are omitted, dense labels are thinned, tooltips and table retain all values. This is a local presentation toggle, also used in focus view.
- Disabled Goals and Shared workset controls retain their concise names without an unavailable suffix.
