## 3. Accepted owner intent

Treat the following decisions as already accepted. Do not ask the owner to
repeat or reconfirm them.

### Product

Custometry is a self-hosted B2C retail analytics and forecasting platform
covering governed data, semantic metrics, analysis, segmentation, research,
forecasting, analytical documents, collaboration, reporting, administration,
and observable reusable computation.

### Included UI scope

- adaptive responsive Web;
- all current route, overlay, shell, flow, transient, system-state, and
  non-visual surfaces;
- one common multi-page Analytical Document model for dashboards,
  workbook/reports, and narrative research;
- universal guided/advanced block authoring;
- exact document/page/block/data collaboration;
- reusable time-aware segments;
- digital acquisition, web/app journeys, offline/online conversion,
  attribution, and unit economics;
- products, categories, hierarchy, assortment, inventory, availability,
  pricing, markdown, and category analytics;
- adoption administration and analytical-performance administration;
- accessibility, RU/EN localization, responsive behavior, Result Trust,
  Focus/Explore, and large-document performance requirements.

### Excluded scope

- mobile-specific information architecture or mobile application design;
- B2B sales ontology;
- campaign activation or reverse ETL;
- arbitrary browser notebooks, user code, or ungoverned SQL;
- probabilistic identity matching;
- algorithmic attribution or causal claims without separate authority;
- ratings, employee scoring, or leaderboards;
- copying another analytics platform or treating feature parity as the target.

### Visual direction

The supplied RU/EN HTML pilot is accepted only as a visual-language and
analytical-density anchor:

- calm professional visual character;
- compact analytical density;
- concise KPI and context chrome;
- visible Result Trust;
- Focus/Explore interaction character;
- RU/EN content stress evidence.

The pilot is **not** authority for:

- exact screen composition;
- fixed KPI → chart → table ordering;
- complete information architecture;
- frontend architecture;
- final component implementation;
- responsive acceptance;
- mobile-specific composition.

Do not merely polish or extend the current pilot screen during G0.
