# Historical August 5 visual pilots

The [Russian](ui-an-004-ru.html) and [English](ui-an-004-en.html) HTML files
are byte-exact references preserved from the source checkout. Their
[manifest](manifest.json) records the original sizes and SHA-256 hashes.

The [accepted target UI concept](../target-pilot/README.md) supersedes these
earlier pilots. These files preserve historical visual work; they do not
select a competing current target, reinstate a retired workflow, or prove
production behavior. The original HTML is preserved without modification,
including its original Vite entrypoint references. These preserved sources
are not certified as standalone runnable demos.
